# ADR-005: очистка XML-комментариев и отключение онлайн-базы моделей Gazebo

## Контекст

Два отказа, которые выглядели как проблемы модели робота, но таковыми не были.

1. `gazebo_ros2_control` (Humble) передаёт описание робота в `controller_manager`
   командой `--param robot_description:=<urdf>`. rcl разбирает значение как YAML
   plain-scalar, а последовательность `": "` внутри XML-комментария (например
   `<!-- base_link: корень -->`) делает строку невалидной:
   `mapping values are not allowed here`. `controller_manager` не стартует,
   спавнеры контроллеров падают по таймауту.

2. `gzserver` при старте синхронно опрашивает онлайн-базу моделей
   `models.gazebosim.org` (`ModelDatabase.cc`). В контейнере или за прокси запрос
   висит бесконечно: строка `Loading world file` не появляется, сервис
   `/spawn_entity` не создаётся, `spawn_entity.py` падает через 30 с.

## Решение

1. Описание грузится через единый helper `arm_description/robot_description.py`,
   который вырезает XML-комментарии:
   `_XML_COMMENT.sub('', urdf)` (`re.compile(r'<!--.*?-->', re.S)`).
   Комментарии семантики не несут, поэтому потерь нет.

2. В `gazebo.launch.py` перед запуском сцены выставляется
   `SetEnvironmentVariable('GAZEBO_MODEL_DATABASE_URI', '')` — запрет похода в сеть;
   используются локальные модели из `/usr/share/gazebo-11/models`.

Плюс мир передаётся явным путём (`share/arm_description/worlds/arm_world.world`) и
этот каталог установлен в `setup.py`, иначе `gzserver` молча грузит пустой мир.

## Последствия

- Оба правила описаны в одном месте и покрыты тестами
  (`arm_description/test/test_robot_description.py`, проверка на отсутствие
  `<!--` и на наличие `gazebo_ros2_control` только при `use_gazebo=true`).
- Модели из онлайн-базы в этом воркспейсе недоступны осознанно.
- Комментарии в xacro остаются для людей: их удаляет helper, а не автор модели.

## Отклонённые альтернативы

- Передавать URDF файлом (`--param robot_description:=$(cat ...)`) — обходит YAML,
  но не решает пункт 2 и ломает единый путь загрузки описания.
- Убрать комментарии из xacro руками — правило будет нарушено первым же
  комментарием с двоеточием.
